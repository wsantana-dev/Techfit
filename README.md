🏋️‍♂️ TechFit

TechFit é uma plataforma digital voltada para o mundo fitness, unindo tecnologia e saúde.
Nosso objetivo é simplificar o acesso a treinos, planos e recursos inteligentes para quem busca qualidade de vida e performance.

🚀 Funcionalidades

📋 Planos de Treino: acesso a treinos personalizados para diferentes objetivos.

💳 Assinaturas Premium & Gold: desbloqueie recursos exclusivos.

📱 Design Responsivo: interface moderna que se adapta a dispositivos móveis.

🔔 Notificações Pop-up: lembretes e confirmações interativas.

🖥️ Tecnologias Utilizadas

Frontend: HTML, CSS, JavaScript

Controle de Versão: Git & GitHub
